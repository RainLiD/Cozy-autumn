# Ламповый вечер

Уютная комната с lo-fi музыкой, которая сочиняется прямо в браузере. Сцена нарисована на SVG, звук собирается через Web Audio API, без библиотек и готовых сэмплов.

## Управление

| Клавиша | Действие |
|---|---|
| Пробел | пауза |
| ← → | соседние треки |
| G | новый трек |
| H | спрятать интерфейс |
| Esc | остановить подборку |

## Как запустить

Открой `index.html` в любом современном браузере. Для круглосуточного стрима допиши `#stream` в конец адреса.


## English

A cozy cartoon room with lo-fi music generated in the browser in real time. Everything lives in a single HTML file: an SVG scene and a Web Audio synthesizer that builds chords, drums, bass and melodies from seeds. It also has a stream mode for OBS, a mix builder that writes timestamps for video descriptions, and an in-browser recorder that saves a mix as a video file.

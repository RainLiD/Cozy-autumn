Треки

    Пробел — пауза, стрелки — соседние треки, G — новый трек, H — спрятать интерфейс. Кнопка со списком наверху собирает подборку для видео с таймкодами. Каждый трек собирается из случайного «зерна», поэтому сгенерированные треки сохраняются и звучат одинаково при повторе. Для стрима добавь #stream в конец ссылки или открой страницу в OBS: кнопки спрячутся, появится подпись с названием трека, а треки будут сменяться сами.

    Код для OBS:

    «Записать видео в файл» работает в Chrome и Edge на компьютере, если страница открыта с GitHub Pages или из файла index.html. Сначала нажми F11, чтобы видео было во весь экран, потом разреши браузеру показ этой вкладки. Запись идёт в реальном времени: часовая подборка пишется час. Не переключай вкладку и не сворачивай окно, в конце файл сам сохранится в «Загрузки». Esc останавливает подборку раньше, записанное при этом сохраняется.
